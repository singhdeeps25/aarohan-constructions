# Aarohan Constructions — refreshed website demo

Responsive, no-backend website built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` in a browser or use VS Code Live Server.
4. No build process or package installation is needed.

## Files
- `index.html` — page content and accessible navigation
- `styles.css` — responsive layout, typography, cards, colour system and reduced-motion support
- `script.js` — mobile navigation, gallery filters, photo count, image lightbox with next/previous controls
- `assets/aarohan-logo.svg` — custom scalable vector logo
- `assets/*.jpg` — owner-provided site photographs
